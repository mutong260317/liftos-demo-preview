## P0

### P0-1 — `countSeedPRs()` guessed PRs from weights
- **Cause:** Dashboard PR count fell back to hack_squat≥105 / bench≥80 heuristic when `h.prs` missing
- **Impact:** Fake PR numbers on production data
- **Fix:** Removed function; PR count only from `h.prs` real fields
- **Test:** `qa-v031-stabilization` no seed PR guess; history without `prs` → 0
- **Status:** **Fixed**

### P0-2 — `?demo=1` polluted production `liftos.history`
- **Cause:** SeedHistory merged into production key
- **Impact:** After visiting demo URL, real user history contaminated
- **Fix:** Demo overlay key `liftos.demo.history`; `getHistoryForStats()`; export only production history; `clearDemoOverlay()`
- **Test:** production → demo → production leaves `liftos.history` unchanged
- **Status:** **Fixed**

### P0-3 — Import proceeded when backup failed
- **Cause:** backup failure only logged
- **Impact:** destructive import without durable pre-snapshot
- **Fix:** abort import with `BACKUP_FAILED` if snapshot fails
- **Test:** monkeypatch snapshot write throw → import aborted, data intact
- **Status:** **Fixed**

### P0-4 — `replaceExercise` orphaned `supersetGroup`
- **Cause:** new exercise object dropped group without unlinking partner
- **Impact:** partner stuck in SS cycle with no partner / broken nav
- **Fix:** inherit group if ≥1 other member remains; else unlink entire group
- **Test:** replace SS member → no orphan groups
- **Status:** **Fixed**

### P0-5 — Duration progression / stats risk
- **Cause:** progression engine could propose kg progression for plank-like exercises
- **Fix:** duration exercises return hold + no weight suggestion
- **Test:** progression on plank does not suggest +kg
- **Status:** **Fixed**
